## 浏览器覆盖

- 首页六方向、现有内容入口、非点击的未完成主题，七篇文章及来源跳转。
- 方向上下文的已读/跳过/下一篇，求助章节在不同方向的不同后续。
- 可选睡眠记录、输入转义、单条删除确认、旧练习重置的作用范围。
- 回忆时原文从 DOM 收起；对照遗漏；合理干扰选项；错误反馈和重试；完成与稍后复习。
- 真实说法搜索、快捷键、空状态、关闭后焦点返回、非法路由恢复。
- 世界地图 SVG 深入口、缩放、复位、鼠标拖动、键盘平移/节点选择，价格问题不冒充单一因果链。
- 独立旧观察、草稿、价格先预测后揭示、修改参数后隐藏旧结果、各练习状态和返回路径。
- 1440×900、390×844 下截图；手机六方向/七篇文章/全回忆流程/地图/搜索无页面横向溢出，中文正文不小于 17px；减少动态效果与键盘进入可用。

本轮实际查看了桌面首页、睡眠文章、练习完成页，以及手机首页、睡眠文章和练习截图。截图不是面向所有设备的完整无障碍审计，也不证明读者学会了相关技能。
