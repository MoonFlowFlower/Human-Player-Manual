# 产品方向

EARTH — Player Manual 是给普通人阅读的现实生活与世界运作说明书。入口要让人看清学习方向，找到眼前需要的问题，理解机制，做一个适合的小尝试，并知道下一步去哪里。

## 当前体验

首页直接看到六个方向；生活基础与学习方法优先，但可以并行。六个方向不是年龄阶段，没有人生总分，也不把收入、婚姻或创业设成共同终点。

本轮只完成七篇基础章节和一条「学会学习」练习闭环。其他领域提供清楚的范围说明、可用旧内容和未完成主题，不扩大占位文章数量。

世界地图保留它擅长的关系浏览。旧面包旅程展示生产、物流、成本和信息，不再是全站默认主线。学习路线与地图通过内容 id 和具名关系共享材料。

## 编辑与设计

约 70% 的投入优先用于交互、信息架构、视觉语言、阅读与完整练习，约 30% 用于内容数量。保留纸色底、墨色正文、朱红标记和原有 SVG 地图。桌面用分区路线概览，手机用适合触摸的纵向阅读，不把大图作为门槛。

中文按钮写清操作结果。先解决读者的问题，再解释背景；不反复声明产品原则，不把困难都归为自律问题，不用空泛承诺。健康、制度与风险内容需要可核实来源和适用范围，不用练习结果代替专业判断。

阅读不设题目关卡。练习反馈要指出具体误解，可重试；已读、跳过、练习完成、笔记草稿与已记录分别表示真正发生的行为。

## 暂不扩展

本轮不增加账户、服务器、数据库、实时 AI、3D 或通用题库。没有验证的人类学习效果不宣称有效；浏览器与单元测试只验证产品行为。后续优先根据真实使用中卡住的位置改进，不以条目总量衡量完成度。
