# EARTH / Experience-first slice

首轮70%精力用于交互、信息架构、视觉和完整学习闭环；30%用于内容数量。

**Scope:** One coherent route — a loaf of bread from its inputs to the table. Twelve compact, connected concepts; three validated quest stages; two curated task recipes. No account, backend, AI API, CMS or empty future topics.

**Visual direction:** Editorial field atlas. Warm paper, charcoal ink, vermilion trace. Oversized serif Latin typography, Chinese-led interface, hairline coordinate grids and deliberately labeled relationships. No stock hero, arbitrary 3D globe, glass cards or pixel UI.

**Learning loop:** Question → curated recipe → inspect graph → read a mechanism → predict a model outcome → receive explanatory feedback → make a real observation and distinguish it from an inference → save local progress and expose a next path. Reading alone does not count as mastery. All knowledge remains browsable.

**Architecture:** Native TypeScript and CSS; no runtime dependency. Shared typed content and graph indexes feed all views. Hash routes preserve navigation and work on static hosts. An SVG atlas is retained on desktop, with a separate focused-node mobile explorer. localStorage is optional, validated and failure-tolerant. Native dialog handles command-palette focus. Build includes a self-contained offline HTML.

**Evidence:** Source-backed general descriptions, explicitly editorial edge models, and synthetic cost assumptions. No market forecasts or jurisdiction-specific advice. Every source has its scope and checked date; unverified observations are labeled self-reported.

**Acceptance:** Desktop 1440×900 and mobile 390×844 screenshots, keyboard search and dialog restore, graph pan/zoom/reset, deep links/back navigation, full quest completion with wrong-answer recovery, reload persistence, malformed/blocked storage handling, narrow-screen overflow and reduced-motion checks. Production build and strict typecheck.
